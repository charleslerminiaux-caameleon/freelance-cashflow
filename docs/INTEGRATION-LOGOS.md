# Logos des intégrations

Les logos identifient les services connectables dans Freelance Cashflow. Ils restent les marques de leurs propriétaires ; aucune licence libre ni affiliation n’est revendiquée. Les fichiers sont servis localement et leurs proportions sont préservées.

Sources officielles vérifiées le 24 septembre 2026 :

- Qonto : fichier existant inchangé, [kit presse](https://qonto.com/en/press/kit), [SVG officiel](https://qonto.com/blog/assets/logo-7d4cecd23c516a73d28522b73227cb8bdc80cbbe1d7c83d9228a7e0ab84a0852.svg). Provenance initiale détaillée dans QONTO.md.
- Tiime : fichier vectoriel existant conservé ; logo coloré correspondant à celui du [site Tiime](https://www.tiime.fr/). Le site référence `https://www.tiime.fr/hubfs/raw_assets/public/Tiime%202024/assets/img/logos/tiime-logo-color.svg` ; son téléchargement direct répond 403. Aucun nouveau dessin ni mot-symbole n’a été créé.
- Pennylane : [SVG du site officiel](https://www.pennylane.com/_nuxt/logo.BkRDgVYD.svg), téléchargé sans modification depuis le logo de navigation de [pennylane.com](https://www.pennylane.com/fr).
- Revolut : [mot-symbole noir officiel](https://assets.revolut.com/Brand/Retail/Logos/Wordmark/Revolut_Black.svg), référencé par le pied de page de la [documentation développeur](https://developer.revolut.com/). « Business » est un libellé de produit adjacent, pas une modification du logo.
- bunq : variante SVG noire officielle extraite, sans modification des tracés, du composant `LogoInternal.wwAFAZI4.mjs` servi par `framerusercontent.com/sites/4FAXO91YsFSHiTJ41BBvmM/` et référencé dans le [site officiel bunq](https://www.bunq.com/).

Les nouveaux SVG ont été inspectés : aucun script, lien externe ou événement actif. Leurs rendus ont été vérifiés dans Chromium sur fond clair.
